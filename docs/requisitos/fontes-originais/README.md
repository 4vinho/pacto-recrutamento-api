# Fontes originais

Esta pasta preserva os requisitos e documentos de preparação anteriores à
reorganização. Eles servem como histórico e fonte de decisões, mas a navegação
vigente começa em [Requisitos do backend](../README.md).

Em caso de divergência:

1. O desafio técnico original define o escopo.
2. A nova estrutura registra a interpretação atual.
3. Decisões marcadas como pendentes precisam de validação antes do código.
