# Infra: vaga

- Repositórios JPA para `vagas`, `perguntas_vaga` e `requisitos_vaga`.
- Índices em responsável e FKs da vaga.
- Consultas ignoram registros excluídos por padrão.
- Status e tipos de resposta são persistidos como texto.
- Migrations criam FKs, checks de ordem positiva e restrições nomeadas.
