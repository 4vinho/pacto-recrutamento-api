# Services: template de vaga

## Casos de uso

- Criar, atualizar e excluir template.
- Criar, atualizar e excluir perguntas e requisitos do template.
- `CriarVagaAPartirDoTemplate`.

## Regras

- Apenas papel administrativo.
- A cópia para vaga acontece em uma única transação.
- A vaga copiada passa a ser independente do template.
