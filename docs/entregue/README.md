# Funcionalidades entregues no backend

Levantamento realizado em 1º de agosto de 2026 a partir do código-fonte, das
migrations, dos testes e das configurações do repositório. O desafio original é
a referência de escopo. Uma classe ou DTO isolado não foi considerado entrega:
foram verificados controller, caso de uso e adapter quando aplicável.
