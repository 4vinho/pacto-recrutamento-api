# Recrutamento API

Backend do sistema de recrutamento interno.

## Requisitos

- Java 8
- Maven 3.8+
- PostgreSQL

## Executar

Configure `DATABASE_URL`, `DATABASE_USERNAME` e `DATABASE_PASSWORD` se os
valores padrão não atenderem ao seu ambiente. Depois execute:

```shell
mvn spring-boot:run
```

## Testar

```shell
mvn test
```
